# 交互仿真三路线设计

## 意图

让评委在同一工程页面中完成“选取工况—修改参数—真实运行—观察事件与指标变化—导出证据”，证明平台不是固定动画。

## 方案取舍

- 采用：把B冻结的S1/S2/S3黄金轴封装为快捷路线，只填充八项轴、策略与seed，仍调用真实后端。
- 不采用：为三条路线保存前端固定结果；这会退化成演示数据。
- 不采用：在浏览器构造任务、窗口、信道；完整配置必须继续由 `sandbox-axis-v1` 后端编译。

## 交互

1. 三个路线卡：资源充足、健康临界、强链路扰动；选择后填充对应轴并展示“观察重点”。
2. 运行中展示状态与真实进度；“转为后台监控”只结束前台长轮询，不伪称取消后端任务。失败展示后端错误及可重试动作。
3. 运行完成展示本次配置快照、当前编辑配置差异、策略指标和基于事实的结果解读。
4. 任意参数修改均将既有结果标记为历史结果；不得暗示结果已随表单实时变化。

## 边界

- 三条路线均标记为合成工况、非正式实验。
- Learned为0、等效或落后均原样展示。
- 结果解释不得使用“证明优越”“显著提升”等正式结论措辞。
- 组件复用全局 `RunController`，不创建第二套运行状态。
