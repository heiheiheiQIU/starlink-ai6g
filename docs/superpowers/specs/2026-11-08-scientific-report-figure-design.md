# 星地智调报告科研图形双轨设计规范

## 目标

把报告图从“科技风演示卡片”改造成可直接进入正式作品方案的科研图形；PPT展示图继续独立保留。两套图共用同一事实源、术语和数值，但不共用画布与信息密度。

## 核心裁决

1. 报告图与PPT图分轨维护。报告图不再使用16:9演示画布、顶部色条、图号徽章、阴影和UI卡片语言。
2. 报告图使用纯白背景。图内只保留必要的面板标记、坐标、图例和极短注释；完整解释、范围和来源放在Word图题/图注中。
3. 正式图题由报告构建器在图片下方居中生成，SVG内部不重复大标题、图号、证据状态或来源脚注。
4. 图形按最终版心尺寸设计：单栏85 mm；通栏165—170 mm。字号按最终插入尺寸计算，不把1600×900幻灯片缩小后塞进Word。
5. 报告只维护DOCX，不生成报告PDF。图件母版为SVG，并提供白底PNG审阅预览。

## 视觉语法

- 背景：`#FFFFFF`。
- 正文与轴标签：`#263442`；次级文字：`#5E6B75`；辅助线：`#D9E1E7`。
- 主线/结构：深轨道蓝 `#24415A`。
- AI价值与健康状态：青绿 `#2A8C82`。
- 链路、时序或重点对照：链路橙 `#D9912B`。
- 风险或阻断：矿物红 `#C95757`，仅在真实风险语义中使用。
- 单图通常不超过三种强调色；颜色不得替代文字、符号或图例。
- 中文字体优先 `Source Han Sans SC` / `Microsoft YaHei`，英文与数字优先 `Arial`；全图不超过两套主字体。
- 最终插入尺寸下：面板标记10—11 pt，轴标题9—10 pt，刻度与数据标签8—9 pt，脚注不进入图区。
- 数据图去除上、右边框；网格仅保留帮助比较的浅灰主网格。
- 禁止渐变、投影、发光、装饰性圆环、大面积彩色卡片和无信息量图标。
- 箭头线宽、箭头头部和转折半径统一；避免交叉，反馈路径使用虚线并附文字说明。

## 三张样板图

### C-F03：AI与6G双向耦合

- 类型：科研机制图，横向通栏。
- 结构：公开观测与任务状态 → AI价值排序 → 6G可行域与状态约束 → 安全解码与执行；链路结果以虚线返回下一决策周期。
- 必须明确：AI负责价值排序，规则负责可执行性；AI不直接越过安全约束下发控制。
- 不允许：中心大圆、四张UI卡片、顶部巨型标题、内部图号徽章。

### A-F02：教师标签质量审计

- 类型：三面板定量审计图。
- `(a)` 标签信息量：13/20全零、7/20至少一个非零，用水平条形图。
- `(b)` 最优集合辨识度：19/20含idle、1/20唯一非idle最优，用点图/棒棒糖图。
- `(c)` 困难工况覆盖：四类均0/20，用零值覆盖矩阵，明确“旧20样本冻结包”。
- 不允许：环形比例图、结论卡片、视觉化放大无依据的优劣结论。

### B-F02：能量账本校核

- 类型：三面板工程量化图。
- `(a)` 背景段与发送段能耗分解，保留Wh单位和计算口径。
- `(b)` 事件账本阶梯关系与储备能量约束线。
- `(c)` 实现值与手算值的一致性，用紧凑数值对照，不使用大色块。
- 必须注明：仅为指定发送段口径，不外推为整星能耗。

## 图题与图注

- 图片下方居中：`图 N  图题`，宋体/黑体五号或与正文模板一致。
- 图题不使用宣传化结论，应准确回答图展示了什么。
- 图题下可增加左对齐小字号“注：”与“数据来源：”，说明样本量、口径、限制和证据ID。
- 正文先引用后出现图；同一术语、数字和状态必须与claim登记一致。

## 验收

- SVG根背景为纯白；无`filter`、阴影、渐变、内部图号徽章和内部大标题。
- 三张图在165 mm宽度下文字清晰、无遮挡、无箭头穿字和标签截断。
- 所有数字、单位和边界与现有签核事实一致。
- 图形通过结构自动检查、SVG解析检查和人工渲染审阅。
- 只在样板获确认后迁移其余报告图；PPT现有资源不被覆盖。
