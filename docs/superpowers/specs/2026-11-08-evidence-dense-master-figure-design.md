## 1. 设计裁决

报告图不再采用“标题 + 若干圆角卡片”的宣传信息图结构。正式图版同时继承两套参考的长处：

- 以 CUMCM 报告的科学图版结构为版式基准：共享坐标、真实量纲、多面板、局部放大、阈值线、图例与结论导向图注；
- 以“星寿智判”的证据密度为内容基准：从输入、算法、执行、指标、可靠性到边界形成可核查证据链。

## 2. 第一张校准样图

图名：AI 健康感知与 6G 星地传输的闭环证据图。

采用 2×2 四面板结构：

1. **(a) 场景与状态**：航天器、地面站、可见窗口、任务、健康下界与截止期；
2. **(b) 候选价值与约束**：使用冻结教师样本中的真实候选分数和 feasible 标记，展示“评分—安全解码”分工；
3. **(c) 链路事件时序**：使用签核 ACK 丢失样例的真实时间戳，呈现发送、接收、ACK 丢失、超时、重传、去重与最终 ACK；
4. **(d) 能量与业务结果**：使用逐段能量账本绘制累计剩余能量，同时列出有效字节、单位成功比特能耗、按时率和能量违规数。

## 4. 视觉规范

- 170 mm 纯白母版，适配 A4 正文通栏；图内不放总标题和“图X”编号；
- 字体优先 Arial / Source Han Sans SC / Microsoft YaHei；正文最小字号等效 8 pt；
- 主色使用深海军蓝、青绿、琥珀、克制红；颜色表达语义，禁止大面积渐变和装饰阴影；
- 面板标记统一为粗体 `(a)–(d)`；坐标必须含名称与单位；图例不得遮挡数据；
- 报告中的图题置于图下居中，图注说明样本性质、口径和结论。

## 5. 验收标准

- 所有数字可回溯到上述 Git blob 或签核文档；
- 四个面板形成“状态感知→价值排序/约束→传输执行→结果反馈”的闭环；
- 不出现无依据的 learned 增益、置信区间、正式比较或在线在轨回灌主张；
- SVG 母版与 300 dpi PNG 预览同时生成；
- 用户确认样图后，才迁移其余五张主图并接入报告 DOCX。
