# 星地智调项目优化方案与执行计划

> 状态：建议方案，供团队安排后续工作；本文不代表所列改动已经实施或三方已经签收。
> 日期：2026-11-02，时间统一为北京时间／香港时间（UTC+8）。
> 执行说明：后续编码可按 superpowers:executing-plans 逐项执行；如团队另选分工执行方式，保留同样的验收标准。复选框表示待办。

**目标：** 在11月12日内部提交前，形成可换机复现、可现场重算、可追溯结果的星地通信调度原型，并用公平实验确定学习策略的实际价值。

**架构：** 沿用现有单星、单网关、多窗口仿真及 Python 后端、React 前端。学习模型仅为公开 Observation 中的任务和模式评分，统一 Guard 决定可执行动作；接收、ACK、重传、去重和能量变化由独立环境执行，评价器依据实际事件计分。

**技术栈：** Python 3.12、NumPy/PyTorch、Pydantic、FastAPI、pytest；React、TypeScript、Vite、pnpm、Vitest。优先沿用冻结版本，新增依赖必须带来明确验收价值。

**依据：** 10月26日完整方案与三人实施手册、仓库 CONTRIBUTING.md、11月2日 B 进度交接、A learned 验收回执、当前 A/B/C 分支代码及本轮独立复跑。本文是项目级优化与交付计划，具体 learned 进程设计承接现有 B-N4 方案。

## 1. 结论与优化重点

当前最需要解决的是已交付模块尚未组成统一产品，以及学习策略缺少有效效果证据。优先顺序如下：

1. 将已验收的仿真、规则、API、模型和前端集成为可运行版本。
2. 完成 learned 真实决策及失败回退，贯通页面、运行、事件、结果和导出。
3. 改善训练数据的状态覆盖与标签辨识度，运行正式公平对照。
4. 根据结果收敛技术主张，再完成材料和换机交付。

暂缓多星、3D增强、在线训练、通用聊天及更深网络。保留已有演示功能，但新增工时优先用于真实数据接入和证据展示。

## 3. 全局约束与重点检查

- 公开Observation与环境隐藏真值保持分离；同场景比较使用同一任务、信道和能源输入及哈希。
- 旧电池raw_fraction不能直接解释为SOC、容量或在线原生RUL；合成健康边界继续明确标注。
- 保留公共合同每请求最多两种策略的限制，先用配对请求比较；如扩至三种，按仓库规则由A/B/C确认合同及镜像变更。
- 训练归一化仅用训练集；来源轨迹先分组划分，再派生多时刻样本；正式测试不得用于调参。
- 已有验收回执按固定SHA和范围引用；候选、合并结果、正式发布版分别验证。
- main合并遵守相邻角色复核要求；本文不代替实际合并授权或回执。

重点检查五类问题：

| 情况 | 期望行为 | 所属工作包 |
|---|---|---|
| 模型遗漏候选、NaN、异常、卡死 | 可解释拒绝或EDF回退，停止失控推理，保留原因 | WP2 |
| ACK丢失、断窗、同块重传 | 保持协议义务，不重复计收益，不被模型绕过 | WP2 |
| 刷新、断网、分页、运行失败 | 不重复创建run，不混用旧结果，不展示伪成功 | WP3 |
| 同源样本改名、标签大量并列最优 | 检测泄漏与低辨识度，不能据命中率宣称学习有效 | WP4 |
| 运行失败、零交付、模型间相关轨迹 | 全量保留，零分母显示N/A，正确计算配对统计 | WP5 |

| 实验结果 | 可采用的表述 |

## 6. 执行顺序与每日验收方式

关键依赖：WP1统一版本 → WP2真实learned → WP3真实页面与WP5正式实验 → WP6一致材料和发布。

WP4的数据审计/扩样、WP3的页面测试、WP6的正文骨架可以并行；最终模型冻结必须早于正式测试。WP4若不能按时产生通过验收的新候选，使用已有小样本候选开展有限范围验证，模型卡保留限制，不能降低验收口径。

每个编码任务按“失败回归→最小修改→定向通过→相邻接口验证→交接记录”执行；文档调整做内容与链接检查。每日只同步五项：完成物、实际验证、未通过项、需要谁接收、次日首要动作。已有独立验收且源码未变的模块不反复全量重验；变动影响面和最终组合版本必须验证。

后端验证示例（在仓库根；每次使用新的验证目录）：

```powershell
$reviewRoot = Join-Path 'runs' ('verify_' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
New-Item -ItemType Directory -Path $reviewRoot | Out-Null
.\.venv\Scripts\python.exe -m pytest tests -q --tb=short --noconftest -p no:cacheprovider --basetemp "$reviewRoot/pytest" --junitxml "$reviewRoot/tests.xml"
```

前端在自身目录运行 `pnpm install --frozen-lockfile`、`pnpm check`；另保留真实HTTP与浏览器验收记录。上述命令是后续验收入口，不表示本文新列功能已经通过。
