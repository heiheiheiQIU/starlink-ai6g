# R4策略与教师 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 独立交付统一guard、EDF/价值规则、自动策略运行与可调用教师首版，供A/C后续消费。

**Architecture:** 公共Observation→评分→统一guard→原R3环境；教师只在公开预测构建的独立环境内搜索，不接触真值。各方法共用协议/能量参数。

**Tech Stack:** Python3.12/Pydantic/pytest，新增依赖0。

**Spec:** docs/superpowers/specs/2026-10-29-r4-policies-design.md。

## Global Constraints

- H00 schema1.0冻结；不改A/C或legacy。R3证据维持原版本。
- 默认时步2s、载荷1024/头32/ACK16byte；功耗W/能量Wh/时间s。
- 单在途；策略只读Observation；预测下界可行不等于真实安全。
- 教师12任务/25候选/120步、200ms/候选上限，显式超时/gap与适用范围。

## Review Focus

- 无当前窗口、跨速率/期限、在途/过期元数据：不可调度对象不能被高分绕过（Task1）。
- 分数NaN/缺idle/未知task、模型异常/超时：完整候选校验与明确规则回退（Task1）。
- 估计与真实轨迹不一致：guard只看预测，环境独立留拒绝或负能量证据（Task2）。
- 教师超时/全零标签/不支持状态：不能称最优，idle与候选完整，分数尺度固定（Task3）。
- wall-clock耗时、分支独立状态、配置/hash版本：不得污染科学重跑或跨策略串状态（Task2/3）。
