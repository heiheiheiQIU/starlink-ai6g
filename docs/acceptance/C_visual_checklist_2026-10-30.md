# C 前端视觉验收清单（C-N1/C4 收尾）

日期：2026-10-30。用途：截图与录屏证据的采集脚本；验收人=用户（队长C），逐项打勾后作为视觉验收回执附件。
设备要求：1920×1080 与 1366×768 各跑一遍；浏览器建议 Chrome/Edge（与演示环境一致）。

## 一、分辨率与排版（每分辨率各截一张全页）

- [ ] 1920×1080：六页面（主舞台/总览/AI助手/对比/证据链/资产）无横向滚动条、无元素重叠
- [ ] 1366×768：页面最小宽度 1180px 生效，出现横向滚动条但不破版、不遮挡左侧导航与顶部横幅
- [ ] 所有文字 ≥14px（含表格、徽章、图例、按钮）；等宽字体数字对齐不跳行

## 二、六步主舞台动效（录屏 20-30 秒）

- [ ] 自动演示一键走完六步，每步状态徽章正确切换（估计层/AI+6G决策层/执行证据层）
- [ ] ①任务到达：新任务掉落动画＋顶部计数同步增加；删除末项计数同步减少
- [ ] ②窗口预测：拖动滑杆窗口条移动；"显示事后真实窗口"出现灰色虚线且标注"策略不可见"
- [ ] ③AI评分：三条分数条生长动画；决策结果卡弹出（最高分任务×模式→交给约束解码）
- [ ] ④约束解码：fast 档能量储备红闪否决；字节配额三步计算动画逐行出现
- [ ] ⑤发送/确认：光束、1024B 数据块、ACK 三个动画与图例一致；注入 ACK 丢失后显示"下一窗口重传·网关去重"
- [ ] ⑥评估：生成报告后指标出现、曲线绘制、证据卡弹出
- [ ] 悬浮球：右下角不遮挡内容；点击弹出面板；"打开完整对话页"跳转正常

## 三、数据源状态（断网联调，录屏 15 秒）

- [ ] 后端未启动：证据链页显示琥珀"演示数据模式"，文案含"契约样例，非真实运行结果"
- [ ] 启动后端后已存 run：自动恢复＋轮询，不重复 POST（浏览器 Network 面板验证只有 GET）
- [ ] 中途停掉后端：橙色"服务连接失败"横幅＋重试按钮；重启后端点重试恢复"已连接实验服务"
- [ ] failed run：显示失败、无正式指标、停止轮询

## 四、动效偏好与可访问性

- [ ] 系统开启"减少动态效果"后，掉落/呼吸/脉冲类动画停止（prefers-reduced-motion 生效）
- [ ] 全部按钮可用键盘 Tab 聚焦并 Enter 触发（抽查六步控制条与重试按钮）
- [ ] 深色主题下琥珀/青色/靛蓝对比度可辨认（不刺眼、文字可读）

## 五、证据归档要求

- [ ] 每个分辨率：6 张全页截图 + 1 张"数据源演示模式"截图，文件名含页面与分辨率
- [ ] 动效录屏：主舞台 30s + 数据源状态 15s，MP4/H.264，≤50MB 每段
- [ ] 截图/录屏放入 `前端图片/视觉验收_2026-10-30/`，并在本文件打勾记录完成时间
