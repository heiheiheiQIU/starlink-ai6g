`events.jsonl`，重新调用仓库正式 `evaluate()`；所得指标字典与顶层 API
`results.json` 的对应 `by_policy` 逐字段完全相等。

字节级复现，且不能用本次单场景差异宣称 edf/value 性能优越。

## 非阻断审计问题：子策略 seed 记录不一致

顶层权威 `config.json`、`results.json` 和 `manifest.json` 正确记录请求
`seed=7`，顶层 `config_hash` 也覆盖 seed。两份子策略 `results.json` 则沿用
底层 CLI 固定值 `seed=0`，子策略 `config.json` 不含 seed。

当前交付明确是确定性、零随机损失，manifest 也声明 seed 仅记录、不产生随机抽样；
因此该差异不改变本轮事件和指标，A 不据此否决当前指标交付。但在引入随机信道、
随机场景生成或把子策略结果作为独立正式结果之前，B 必须把请求 seed 传入子运行并
统一顶层/子层记录，避免审计歧义。
