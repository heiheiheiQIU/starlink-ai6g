## 〇、叙事主线（同 v1，全文唯一）

主线不变：**星上能量与链路窗口构成刚性约束、任务价值异构 → 提出"学习评分器＋约束解码器"解耦架构 → 以预登记配对实验体系作出诚实裁决 → 全链路可复现交付。** 各章论证角色表见 v1；本章新增四条**工程纪律**，与叙事主线并列生效：

### 纪律1：语义引用，禁止手写编号
- 公式一律语义标签：`式(eq:wot)`（目标函数）、`式(eq:tx-energy)`（发送能耗）、`式(eq:tx-time)`（传输时长）、`式(eq:quota)`（字节配额）、`式(eq:channel)`（共享信道随机数）、`式(eq:teacher)`（教师目标）；
- 图/表同样语义标签：`图(fig:scene)`、`图(fig:arch)`、`表(tab:interfaces)`、`表(tab:decisions)` 等；正文引用一律 `式(eq:wot)`/`表(tab:decisions)`；
- 转换时由 Pandoc 交叉引用或 Word 题注自动编号；**任何人工键入的"表3/图4"即视为违规**；
- 编号顺序变更时只改一处（标签定义），引用自愈。

### 纪律2：claim 唯一事实源与宏化
- 建立 `docs/report/claim_values.json`：唯一事实源，结构为
  `{ "claim-E1": { "value": ..., "unit": ..., "source": "run_id/文件", "hash": "前缀", "status": "signed_off|pending", "scope": "失效边界" } }`；
- 生成规则：由证据目录的 verification.json/manifest 经脚本 `scripts/generate_claim_values.py` 生成，**禁止手工编辑数值**；
- 正文数字一律写占位 `{{claim-E1}}`；11/07 实验签核后运行脚本填充；
- 数值变更流程：改证据库 → 重跑脚本 → 反向复核（纪律4）→ 发布检查（纪律3）。

### 纪律3：发布门禁（残留检查脚本）
`scripts/check_material_gate.py` 在发布前执行，任一命中即拒绝打包：
1. 残留 `{{claim-*}}` 占位；
2. 残留 `[待签核]`、`待填`、`TODO`、`\Pending`；
3. claim_values.json 中存在 `status != "signed_off"` 却已被正文引用的条目；
4. 手写编号模式（如正文出现"表3"且非自动生成）；
5. 身份信息（校名/姓名/绝对路径/logo）。

### 纪律4：禁用措辞清单（材料全篇生效）
- 未经配对自助法区间检验：禁止"显著优于""明显提升""大幅改善"；
- 未经定义：禁止"最优""实时""在线自适应"（在线=仅指页面实时交互时须注明）；
- learned 行为声明：必须带"在冻结合成支持域内"前缀；禁止"泛化""星上性能"表述；
- 禁止"完整双向热质耦合"式过强措辞（通用规则：机制描述不超过已验证范围）；
- 规则矩阵数字（0.487/0.553）引用时强制标注"开发期规则验证，非正式实验"；
- 能量相关：禁止把"零负能量段"表述为"始终高于储备线"。

### 纪律5：修改影响链（反向复核 SOP）
```
模型/实验参数 → 证据库(verification.json) → claim_values.json → 图表 → 正文 → 摘要 → 视频脚本 → PPT
```
任何上游变更按此链**反向**逐层复核；禁止只改摘要数字或只替换图片；变更记录写入 DECISIONS 等价物（docs/materials/DECISIONS.md）。

## 一、报告正文（章节同 v1，以下仅列 v2 增补）

- 摘要：≤300字一页内；结构=背景一句→技术路线→三项贡献→四档口径结论（签核后填）；每处数字用 `{{claim-*}}`；
- 第1章：政策引用加"失效边界"（如"白皮书愿景，非工程指标"）；问题形式化六式全部语义标签＋适用域（见纪律6）；
- 第3章：表(tab:data-overview)（数据总览）与表(tab:label-audit)（标签审计对照）的"失效边界"列必填；
- 第4章：learned 能力声明一律带支持域前缀；表(tab:modelcard) 复用 claim-D3 并注明样本规模限制；
- 第5章：四档口径表为唯一输出；结果表引用 `{{claim-X*}}`；失败案例引用事件流 run_id；
- 第6章：复现清单对齐官方规范（附录B）；资源数字引用 claim-E2；
- 附录C：每条 claim 增加"失效边界"列（沿用 v1 模板＋scope 字段）。

### 纪律6：公式适用域与动机同句（六式补全）
| 标签 | 公式 | 适用域/口径（写入方程行或紧邻句） |
|---|---|---|
| eq:tx-energy | $E_{tx}=P_{tx}T_{tx}/3600$ | 仅发送段能耗；不含背景/ACK 段 |
| eq:tx-time | $T_{tx}=(L+32)\times 8/B$ | 块=载荷+32B头；B 为该模式速率 |
| eq:wot | 式(3) | 仅"完整接收且≤deadline"计入；分母=全部到达任务 |
| eq:quota | $Q=\min(L_{max}, B\Delta t/8)$ | min 语义；下取整按实现口径 |
| eq:channel | 式(5) | 同一 seed/stream/时间索引；与策略无关 |
| eq:teacher | $\max\sum_a u_a$ | 零损失预测模型；gap=0 才准入 |

### 纪律7：图表调色板（报告专用，一次定义）
浅底深描边双色系（与前端暗色分离）：主色 `#1565C0`（蓝）、辅色 `#2E7D32`（绿）、强调 `#E65100`（橙）、警示 `#AD1457`（红紫）、中性 `#333`；填充为各主色 8% 淡底。图表生成脚本 `scripts/report_figures.py` 统一引用，禁止页内另配颜色。

### 纪律8：官方规范终检清单（发布前逐项）
摘要≤1页；正文结构完整；附录含支撑材料文件列表＋全部源代码（无程序则声明）；**全篇无身份信息**；引用按规范列表（URL＋访问日期＋版本）；PDF 单独文件 <10MB；视频 3-5 分钟 <300MB；命名规范按赛道通知。
