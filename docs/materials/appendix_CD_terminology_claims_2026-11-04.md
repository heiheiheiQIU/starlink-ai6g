|---|---|---|
| T1 | 学习评分器 | 基于冻结模型对公开观测下各候选动作输出评分的学习组件；不直接决定执行动作 |
| T2 | 约束解码器 | 依据窗口、数据位置、单在途、能量储备与字节配额等约束将评分转换为可执行决策的组件 |
| T3 | 教师求解器 | 在公开预测模型上执行预算受限树枚举、输出最优或可行下界标签的监督信号源 |
| T4 | 来源组 | 同一生成来源（轨迹）的样本集合；数据划分以来源组为单位 |
| T5 | 契约样例 | 仅用于界面与流程演示、明确标注非实验结果的固定数据 |
| T6 | 真实运行 | 由后端服务实际执行并产生事件流与指标的一次实验运行 |
| T7 | 已签核结果 | 经实验冻结、独立复算与三方签核后允许写入材料的数据 |
| T8 | 加权按时交付率 | 按时完整交付任务权重之和与全部到达任务权重之和的比值（式(3)） |
| T9 | 公开能量下界 | 仅由公开观测与能量账本可推得的能量下界估计 |
| T10 | 共享随机信道 | 以版本、种子、流、时间索引为键生成的确定性随机数序列，保证不同策略面对同一外部随机性 |
| T11 | 单在途 | 任一时刻至多一个任务块处于在途状态的协议约束 |
| T12 | 重传锁 | 确认超时后仅允许重传原任务原块的协议状态 |
| T13 | 观测隔离 | 信道种子、真实随机值与接收端状态不进入公开观测的原则 |
| T14 | 结构掩码 | 依据任务状态（在途、过期、剩余量为零）标记候选不可执行性的掩码 |
