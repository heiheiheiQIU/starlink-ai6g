# 星地智调专业图件包 v2

生成日期：2026-11-07。v2 是在 v1 基础上的完整复核修订版，v1 原样保留用于历史追溯。

## 交付内容

- 15 张 1600×900 可编辑 SVG；
- 15 张同尺寸 PNG 预览；
- 1 张无文字主题背景 PNG；
- `manifest.json`：色板、字体、状态与 SHA-256；
- `scripts/generate_visual_pack.mjs`：确定性生成源。

SVG 是报告、PPT 和后续排版的正式源文件；`previews/` 仅用于快速审阅与不支持 SVG 的场景。不得把 PNG 预览反向覆盖 SVG 源。

## v2 相对 v1 的主要修正

1. 所有图加入图号和证据状态标签，图区分“机制与设计图”“已签核数据”“待三方签核”。
2. 图标题改成可直接回答评委问题的结论句，副标题交代图型、变量或数据口径。
3. 重写通用箭头函数，支持左向、斜向与回传箭头，消除泳道时序中的错误箭头和标签碰撞。
4. B-F01 补全正常确认与 ACK 丢失后的超时、同序号重传、接收端去重和不重复计收益。
5. B-F02 加入单位、能耗公式、事件阶梯与手算差值，避免只有装饰性柱形。
6. B-F03 加入 3×3 工况坐标、顺序/发散图例和“360 次开发期规则运行”限制。
7. B-F04 加入 `seed / random stream`、`input_hash`、10,000 次 bootstrap 和四档裁决口径。
8. C-F04 改为单向证据流水线，明确事实源不可被材料反向覆盖。
9. C-F05 补齐每阶段输入、动作、门槛与放弃线。
10. C-F08 将无坐标线性条改为明确标注的 log10 数量级点图，保留原始计数，避免跨数量级视觉误导。

## 使用约束

- A-F02、A-F03、B-F02、B-F03、C-F08 只能按图内来源与限定口径引用；
- B-F03 是开发期规则验证，不是 AI 正式实验结果；
- B-F04 是预登记协议，不代表实验已经完成；
- B-F05 只是安全占位模板，三方签核前禁止增加结果点、胜负颜色、提升率或演示数据；
- 机制图和路线图不构成真实在轨部署证明；
- 主题背景只用于封面/章节页，不得包装为系统截图或实验事实。

## 排版建议

- 报告正文优先插入 SVG/PDF 矢量版本；若 Word 对 SVG 兼容不稳定，再使用 PNG 预览；
- 图题置于图下，格式建议为“图 X 结论性短标题”，图注再写数据源、样本量、单位和限制；
- 单栏图宽不小于 85 mm，跨栏图宽 170–180 mm；缩放后正文文字不小于 7.5 pt；
- 不裁掉右上角图号/状态标签和底部证据脚注；
- PPT 每页原则上只放 1 张主图，口播先讲标题结论，再指向关键证据，最后说限制。

## 重新生成

在 C 工作树根目录执行：

    node scripts/generate_visual_pack.mjs

重新生成后必须重新渲染 PNG 并逐图复核；只看到脚本成功退出不能视为视觉验收完成。
