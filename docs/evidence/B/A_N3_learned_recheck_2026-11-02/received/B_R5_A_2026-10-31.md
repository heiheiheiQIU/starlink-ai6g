## 公平性独立复核

```text
version | seed | stream | time_index
```

其中时间格由 `Fraction(str(time_s)) // Fraction(str(step_s))` 计算。函数没有 policy、task、block、mode 或发包次数参数，因此同一 seed、stream 和物理时间格的外部随机值不随策略改变；data 与 ack 使用不同 stream。A 以 seed=10000、step=0.25、t=0.3 复算：data 两次均为 `0.9851563699059169`，ack 为 `0.9042886041986345`。

## 备注与使用边界

1. 上述 18×10 是 R5 synthetic 规则矩阵的场景/轨迹拆分，不是 A-N3 的 train/validation/test 数据划分；不能把本回执当作训练集冻结票。
2. 同一时间格的 robust/fast 共用随机值但损失阈值可不同；本回执接受的是配对外部随机性设计，不声称两模式统计独立。
3. 本矩阵使用准确健康输入，且参数是合成假设；零负能量段不等于证明始终高于 reserve。
4. EDF/value 数值仅是已登记合成规则验证的复算结果，不能作为 learned scorer、AI 收益、成熟优化器优越性、统计显著性或在轨性能结论。
5. 教师对非零预测损失仍可能返回 `UNSUPPORTED_LOSS`；A-N3 若要覆盖带损失训练场景，需要后续单独的教师能力与数据门禁。

A 因此接受 `50f441a` 的 R5 公平性结构、18×10 场景矩阵完整性与已提交规则结果证据，同时保留以上非阻塞边界。
