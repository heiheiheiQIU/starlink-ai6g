# DS 文档与前端二次审计（2026-11-06）

## 1. 审计范围与结论

- 审计基线：`feature/frontend`，提交 `d60a12f`。
- 文档范围：`docs/report/report_v2.md`、`docs/report/星地智调_作品方案_v2.docx`、`scripts/build_report_docx.py`、`docs/materials/claims_spec.json`。

## 2. 文档审计

### 2.1 必须修复（发布阻断）

1. `星地智调_作品方案_v2.docx` 的节属性只有页边距，没有显式 A4 `w:pgSz`，导致标准渲染器无法确定页尺寸。
2. `build_report_docx.py` 仅追加普通文本公式号，未建立 Word `SEQ` 编号、书签和 `REF` 交叉引用；正文仍出现 `式(eq:...)`、`表(tab:...)`、`图(fig:...)`。
3. 表格只设置居中，没有表头底色、重复表头、列宽、单元格边距、跨页控制和超宽表降级策略。
4. `report_v2.md` 将 claim-E1 的已签核发送段能耗 `0.0303125 Wh` 与包含 ACK 的示例 `0.030903 Wh` 混用，且附录错误声称后者已签核。
5. “95% 区间跨 0”不能证明统计等效。四档名可保留，但必须表述为“等效档（未检出稳定差异）”，不得写成严格等效检验结论。
6. 参考文献 [5]、[6] 仍为占位项；[3] 使用“同上列表页”，不符合正式引用规范。
7. 图表登记均为“待插入”，当前版本尚不能作为正式方案 PDF。

### 2.2 应升级（质量项）

1. 正文 18 工况全矩阵过长，应在正文放结论型汇总/热力图，把全表移至附录。
2. 统一中文宋体、英文与数字 Times New Roman；正文小四单倍行距；标题黑体黑色；公式、图题、表题和参考文献使用独立样式。
3. 所有表格必须以“读者任务”决定列宽，避免平均分配；跨页表重复表头，行不允许拆页。
4. 参考文献统一按 GB/T 7714 风格书写，网络资源含访问日期；政策、白皮书、数据集、软件包分别标明载体类型。
5. 缩短大段政策原文，改为“结论性转述 + 精确页码”，避免材料像资料汇编而非方案论证。
6. 修正“第三方针剂复核”为“第三方交叉复核”，修正“图(tab:figures)”等标签错误。

## 3. 前端审计

### 3.1 已达到的基础

- 七页信息架构完整，主舞台能表达任务到达、窗口预测、AI 评分、约束解码、发送确认、评估证据六步逻辑。
- FIXTURE/真实运行区分已进入页面文案，避免把演示数字伪装成实验结果。
- 星地链路使用统一 SVG 路径驱动数据块与 ACK，GW/SAT 不共线导致的传输轨迹问题已从结构上修正。
- 当前分支存在自动化测试和 TypeScript/Vite 构建门禁。

### 3.2 必须修复（工程化阻断）

1. 顶栏固定显示 `DEMO OBS`，系统状态固定为“演示工作台”；没有清晰的运行模式切换、连接状态、run_id、最后同步时间和失败恢复入口。
2. “自动演示”本质是本地 `setInterval` 切步骤，不消费后端运行状态；不能称为正式工程操作。
3. “单步 +30s”只把动画设为播放，没有推进后端或本地运行机状态；按钮语义与行为不一致。
4. 任务、窗口、评分、约束和证据各步使用分散的组件本地状态，步骤之间没有一个可追踪的统一运行会话；因此演示链条看似连续，数据实际上未贯通。
5. 页面最小宽度 1180px，较窄演示窗口会横向滚动；比赛投屏常见 1366×768，需要专门的紧凑布局门禁。

### 3.3 视觉与动效升级方向

1. 保留深海军蓝控制台与青色主链路，建立唯一语义色：青=链路/在线，靛=AI，绿=成功，琥珀=风险，红=阻断；减少同类蓝色的无区分堆叠。
2. 主舞台需要一条贯穿六步的“运行脉冲轨”，让评委始终知道输入、当前决策和输出，而不是只看到局部卡片变化。
3. 动效必须绑定状态转换：`idle → queued → scoring → guarded → transmitting → acked/failed → evidenced`，暂停、重播、单步与实时模式共用同一状态机。
4. 所有动画提供 reduced-motion 降级；高频呼吸/脉冲只用于当前焦点和风险，不用于普通按钮。
5. 正式模式必须显式展示 API 在线/离线、fixture/real、运行 ID、证据是否冻结，视觉华丽不能掩盖数据来源。

## 4. 裁决

- 文档：保留 DS 的章节骨架与事实材料，重做生成器的正式版式和交叉引用，先纠正口径再扩写内容。
- 前端：保留用户最终裁定的页面结构与视觉方向，不重构为另一套界面；新增统一运行会话与工程状态带，用状态机驱动既有动效。
- 禁止项：不补写未签核实验数字，不把 fixture 当 real run，不以“预测提升”替代正式结果，不移除三方验收门禁。
