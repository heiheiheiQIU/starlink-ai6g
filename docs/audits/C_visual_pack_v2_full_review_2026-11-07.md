## 三、建议图题与口播结构

报告中的每张图使用“两层标题”：正文图题说“这是什么”，图内标题说“评委应得出什么结论”。例如：

- 报告图题：`图 X 发送确认、重传与接收端去重时序`；
- 图内结论：`确认丢失不会重复计收益：系统重传同一数据块并在接收端去重`；
- 图注：`正常路径与 ACK 丢失路径；事件名称以冻结协议实现和验收记录为准。`；
- 口播顺序：先讲结论，再沿箭头讲正常链，最后讲异常链与证据记录。

数据图的图注必须同时包含来源、样本量、单位、统计口径和限制。机制图的图注必须出现“机制/设计图，不代表已完成真实部署”或等价表述。

## 四、尚未解除的边界

1. B-F05 仍是未完成模板；正式实验结果必须由固定脚本生成并经 A/B/C 三方签核后替换。
2. A-F02、A-F03 的旧小样本证据只能支持“标签辨识度和样本量不足”，不能支持 AI 增益。
3. C-F08 只说明外部需求规模，不证明本项目性能、收入、市场份额或真实在轨部署。
4. 主题背景是非数据视觉资产，只能用在封面、章节页或低透明度背景层。
